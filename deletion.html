Expense Assistant - Data Deletion Instructions

Last updated: August 14, 2026

Expense Assistant is a personal project that allows users to submit expense information and receipts through WhatsApp.

How to Request Data Deletion

If you have used Expense Assistant and would like information associated with your interactions to be deleted, you may request deletion by contacting the application owner.

In your request, please identify the WhatsApp number associated with your Expense Assistant interactions so the relevant data can be located.

What Will Be Deleted

Where applicable, data associated with your use of Expense Assistant, including stored expense information and receipt-processing data, will be deleted.

Contact

For a data deletion request, please contact the Expense Assistant application owner using the contact information associated with the application.
