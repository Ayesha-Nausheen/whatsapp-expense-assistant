# Personal Expense Assistant

A personal AI-powered expense tracking project that uses the WhatsApp Business Platform to receive expense information and receipts.

## Goal

The assistant will allow users to send receipt images and expense information through WhatsApp. The backend will process the messages, extract expense data, categorize transactions, store the information, and support expense-related questions.

## Current Development

- WhatsApp Business Platform integration
- FastAPI backend
- Webhook integration
- Receipt processing
- Expense categorization
- Expense storage and analytics
